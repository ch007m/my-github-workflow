# Instructions

- When the user asks to be greeted, use the MCP tools from the `quarkus-agent` server:
  - Call `greetHello` with the user's name to get a hello greeting
  - Call `greetBye` with the user's name to get a bye greeting
- The user's name is optional
- Display the greetings in a friendly format
- Save the greetings to a HELLO.md file
